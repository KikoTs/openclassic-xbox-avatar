# Contributing

Contributions are welcome through issues and pull requests.

Keep the repository source-only. Do not commit:

- `CastleMinerZ.exe`, `DNA.Common.dll`, or other game files;
- decompiled Castle Miner Z or OpenClassic source;
- Xbox Original Avatars binaries, `.winmd` metadata, or generated projections;
- compiled `.exe`/`.dll` files;
- `.ocavatar` files, screenshots containing personal details, or runtime logs.

Build locally with `build.ps1`, run both protocol smoke tests, and describe the
tested avatar outfits and multiplayer configuration in the pull request.
