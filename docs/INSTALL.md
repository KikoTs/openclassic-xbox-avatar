# Installation

Release packages contain no game executable. They are installed over a
working OpenClassic setup.

1. Close Castle Miner Z.
2. Copy the release package contents into the Castle Miner Z game folder.
3. Double-click `OpenClassic Xbox Avatar Manager.exe`.
4. Open Xbox Original Avatars and leave the wanted avatar visible.
5. Double-click `Import Xbox Avatar.exe` and confirm the capture.

The generated avatar is stored at
`OpenClassic Addons/Xbox Avatar/avatar.ocavatar`.

To disable the add-on, run `Disable Xbox Avatar.cmd`. The manager restores the
exact executable it backed up before adding the avatar integration calls. It
also retains an avatar-enabled recovery copy.

Disable the add-on before updating OpenClassic or another base mod, then enable
it again after the update.
